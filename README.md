## Projetos destacados

### System-PITE

[Repositório no GitHub](https://github.com/MiguelSouza0/System-PITE)

Plataforma de gestão pública orientada ao turismo municipal. O sistema conecta turistas, empreendedores locais e administração pública em uma aplicação com recursos de geolocalização e transparência.

Entre as funcionalidades documentadas estão:

- roteiros personalizados com IA auditável;
- filtros e recursos de acessibilidade;
- matriz ESG e relatórios de transparência;
- cadastro e validação de empreendedores locais;
- painéis de gestão para prefeitura e secretaria;
- recursos relacionados à LGPD e validação de avaliações.

**Tecnologias:** Laravel, PHP, PostgreSQL, Blade, Bootstrap, Leaflet, Vite, Docker e Docker Compose.

### Slepy

[Repositório no GitHub](https://github.com/JulioKennedyy/Slepy)

Bot de produtividade para Discord desenvolvido em Python. O projeto transforma sessões de foco em progresso acompanhado pelo usuário.

Principais recursos:

- sessões de foco com notificação ao final;
- timer Pomodoro com períodos de pausa;
- perfil com total de minutos focados;
- sistema de badges baseado no tempo acumulado;
- comandos Slash do Discord;
- persistência do progresso em SQLite;
- arquitetura modular baseada em Cogs.

**Tecnologias:** Python, discord.py, asyncio, SQLite e setuptools.

### SportHub

Projeto acadêmico de aplicação web para gerenciamento e reserva de quadras esportivas.

O projeto trabalha regras de negócio relacionadas ao fluxo de reservas, integração entre frontend e backend, uma API REST e uma interface responsiva.

**Tecnologias:** Java, Spring Boot e React.

## Executar localmente

Como o projeto não depende de backend ou processo de build, basta abrir o arquivo `index.html` no navegador.

Para uma experiência mais próxima da publicação, também é possível usar uma extensão de servidor local, como o Live Server do VS Code.

## Publicar com GitHub Pages

1. Envie os arquivos deste projeto para um repositório público no GitHub.
2. Abra `Settings` no repositório.
3. Acesse `Pages` na área `Code and automation`.
4. Em `Build and deployment`, selecione `Deploy from a branch`.
5. Escolha a branch principal e a pasta `/root`.
6. Salve e aguarde a geração do endereço público.

O arquivo `index.html` precisa permanecer na raiz da branch publicada.
